# What is System Design?

**Q1. What is system design?**
> "System design is the process of defining architecture, components and data flow of a system to meet specific requirements — mainly scalability, reliability and performance."

**Q2. Why is system design important?**
> "Any developer can build an app for 10 users. System design is what makes that app work for 10 million users without crashing or slowing down."

**Q3. What are the goals of system design?**
> "The four main goals are — scalability, which means handling more users; reliability, which means the system always works correctly; availability, which means the system is always accessible; and performance, which means the system responds fast."

**Q4. What is the difference between scalability and availability?**
> "Scalability is about handling increased load — more users, more data. Availability is about ensuring the system is up and running at all times, even during failures. A system can be scalable but not available if it crashes under load."
